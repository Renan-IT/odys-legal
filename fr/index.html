Application Android de livres audio

Informations légales d'Odys

Odys est un lecteur local conçu pour fonctionner hors ligne, sans compte, publicité ni suivi. Cette page rassemble les documents applicables à l'application.

Version du 1er septembre 2026 · Version française de référence

01

Politique de confidentialité

En bref

Odys ne crée aucun compte, n'intègre aucun outil publicitaire, analytique ou de télémétrie et n'envoie pas vos fichiers audio, votre progression ou vos habitudes d'écoute à l'éditeur.

Données conservées sur l'appareil

L'application conserve localement les dossiers choisis, les informations extraites des fichiers audio, les couvertures mises en cache, la progression de lecture, les signets, les préférences, les modifications de métadonnées et les livres LibriVox téléchargés. Ces données servent uniquement au fonctionnement de l'application.

Odys désactive la sauvegarde Android de ses données. Vous pouvez supprimer les livres téléchargés depuis l'application et effacer toutes ses données depuis les réglages Android ou en la désinstallant.

Accès aux fichiers et notifications

Vous choisissez les dossiers audio auxquels Odys peut accéder au moyen du sélecteur de documents Android. L'application demande uniquement un accès persistant en lecture aux dossiers sélectionnés. Sur les versions Android concernées, l'autorisation de notification permet d'afficher les commandes de lecture en arrière-plan.

Connexions facultatives

La lecture des fichiers locaux reste disponible sans Internet. Lorsque vous utilisez les fonctions correspondantes, Odys peut effectuer les connexions suivantes :

  • Apple Books / iTunes Search API et Open Library : recherche facultative de titre, d'auteur, de résumé et de genre. Le titre et, s'il est disponible, le nom de l'auteur sont inclus dans la requête. Les résultats utiles peuvent être mis en cache sur l'appareil.
  • LibriVox : consultation du catalogue et téléchargement d'un livre audio uniquement après votre action. Les fichiers sont stockés localement.

Comme pour toute connexion Internet, ces services reçoivent nécessairement des informations techniques telles que l'adresse IP et l'agent utilisateur. Leur traitement relève de leurs propres politiques. Odys ne transmet pas ces données à un serveur exploité par son éditeur.

Ce site

Ce site statique ne dépose aucun cookie propre et n'utilise ni formulaire, ni mesure d'audience. Il est hébergé par GitHub Pages ; GitHub peut traiter des données techniques de connexion conformément à sa politique de confidentialité.

Vos demandes

Pour toute question relative à la confidentialité, écrivez à odys.contact@proton.me. La plupart des données décrites ci-dessus restent exclusivement sur votre appareil et ne sont donc ni accessibles ni récupérables par l'éditeur.
